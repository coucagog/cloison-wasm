# cloison-wasm

Wrapper `wasm-bindgen` de [cloison-core](https://github.com/coucagog/cloison-core) pour
le navigateur / l'embarqué (edge CLOISON).

> Squelette : la logique arrive avec le STACK qui la porte.

Fait partie du projet [CLOISON](https://github.com/coucagog/cloison) — proxy de
confidentialité PII compatible OpenAI.
